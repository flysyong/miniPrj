# 미니 PJT: 전자제품 AS 접수 Agent

## 무엇을 푸나
고장 난 전자제품의 AS를 신청하려는 소비자가 콜센터를 기다리지 않고 채팅으로 자가 조치를 안내받거나, 기사 배정과 방문 날짜 확정까지 한 번에 끝낸다.

## 활용한 패턴 (Day 1~7)
- Day 1: LCEL chain + Pydantic 구조화 출력 — 가드 판정·접수 정보 추출·평가 판정 결과를 dict로 반환
- Day 2: RAG (Markdown 청킹, Titan v2 임베딩, Chroma, BM25 하이브리드) — 증상으로 FAQ 자가 조치 검색
- Day 3: LangGraph 조건 분기 — 자가 해결 / 접수 / 차단 흐름 라우팅
- Day 5: 가드레일 (정규식+LLM 인젝션 검사, 개인정보 마스킹) — 입력 차단, 로그·LLM 전달 시 마스킹
- Day 7: MCP (FastMCP 서버) — 접수 조회·저장, 기사 배정, 가능 날짜 조회 도구 제공

## 아키텍처
```
POST /query ─▶ 입력 가드레일 ─(차단)─▶ 안내 문구
                   │
                   ▼
              증상 FAQ 검색(RAG) ─(해결)─▶ 자가 조치 안내 후 종료
                   │(미해결)
                   ▼
              중복 접수 확인(MCP) ─(중복)─▶ 기존 접수 안내
                   │
                   ▼
              기사 배정 + 가장 빠른 날짜(MCP)
                   │
                   ▼
              고객 승인(HITL) ─(거절, 최대 3회)─▶ 다음 날짜 재제안 ─▶ '대기' 저장
                   │(승인)
                   ▼
              접수 확정 저장(MCP)
```
